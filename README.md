# Hearthmend

Уютная merge-игра для iPhone в пиксель-арте: сливаешь предметы на поле, выполняешь заказы жителей и отстраиваешь разрушенную бурей деревню.

Дизайн-документ: `docs/design.md`.

## Что уже есть

- Поле 7x9: перетаскивание, слияние двух одинаковых предметов в следующую ступень, обмен местами
- 5 цепочек по 6-7 ступеней (огород, лес, каменоломня, пасека, ферма), описаны в `Sources/HearthCore/Resources/chains.json`. На старте открыты первые три
- Генераторы: тап стоит 1 энергию, два одинаковых генератора сливаются в генератор следующей ступени, который чаще выдаёт предметы повыше
- Завалы в верхних рядах: слияние в соседней клетке снимает слой
- Энергия: максимум 100, +1 за 2 минуты
- Заказы: 4 одновременно, сложность растёт вместе с лучшей собранной ступенью цепочки, награда монеты, звёзды и опыт
- Пузыри: при слиянии с 4-й ступени иногда появляется пузырь с копией предмета, открывается за кристаллы, иначе лопается через 30 секунд
- Продажа предметов и корзина на 6 мест
- Сохранение после каждого действия, русский и английский

Графика из пака Cute Fantasy RPG (Kenmi). Если спрайтов в сборке нет, вместо них рисуются эмодзи.

## Устройство

- `Sources/HearthCore` - правила игры без UIKit (Swift-пакет). Время и случайность передаются снаружи, поэтому всё покрыто тестами
- `Tests/HearthCoreTests` - тесты правил: `swift test` (нужен Swift 5.9+, на Linux тоже работает)
- `Hearthmend/` - приложение: SwiftUI + SpriteKit. `GameStore` связывает ядро с интерфейсом и сохраняет прогресс, `BoardScene` рисует поле и обрабатывает касания
- `project.yml` - проект для XcodeGen, ядро подключено как локальный пакет

## Графика

Пак нельзя выкладывать открыто, поэтому в репозитории лежит только зашифрованный архив `Art/sprites.enc` (как в GameFarm). Сборка на GitHub расшифровывает его ключом из секрета `ASSETS_KEY`. Если секрета нет или ключ не подходит, игра собирается с эмодзи.

Какие клетки пака идут в какие предметы, описано в `tools/sprites.py` (ключи совпадают с `chains.json`). Пересобрать архив: распаковать пак (папка `Cute_Fantasy`) и запустить
`ASSETS_KEY=<ключ> sh tools/pack_sprites.sh <путь к Cute_Fantasy>`.

## Сборка

- Тесты ядра (`.github/workflows/tests.yml`) идут на Linux на каждый push и PR
- `.ipa` (`.github/workflows/build.yml`) собирается на macOS при push в `main` и по кнопке Run workflow, публикуется в Releases. Репозиторий приватный, а минуты macOS считаются x10, поэтому на PR сборка идёт только с меткой `build-ipa`

Локально: `xcodegen generate`, затем открыть `Hearthmend.xcodeproj`.

## Установка через SideStore

1. Открой последний релиз в Safari на iPhone и скачай `Hearthmend.ipa` в Файлы.
2. В SideStore открой вкладку "My Apps", нажми "+" и выбери `Hearthmend.ipa`.
